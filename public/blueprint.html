Section 4

Payment Flows

Paystack — Primary Gateway (Nigeria)
1
Customer places orderPOST /checkout → creates Order (status: PENDING, payment_status: UNPAID, order_number: TAK-YYYY-NNNNN)
2
Initialize PaystackServer calls Paystack API → gets authorization_url → redirects customer to Paystack hosted checkout
3
Customer paysCard / bank transfer / USSD on Paystack's secure page
4
Webhook receivedPaystack POSTs to /api/payment/paystack/webhook → HMAC-SHA512 signature verified
5
Order confirmedOrder updated: payment_status=PAID, status=CONFIRMED, paid_at=now(). Timeline entry recorded.
6
All notifications dispatchedEmail (OrderConfirmed + PDF invoice) to customer · Email (OrderAdminAlert) to admin · SMS to customer · Push to all subscribers
7
Success pageCustomer redirected to /checkout/success?order=TAK-xxxx with full order summary
Flutterwave — Secondary Gateway

Identical flow to Paystack. Key differences:

  • Init: POST https://api.flutterwave.com/v3/payments
  • Webhook: /api/payment/flutterwave/webhook — validated via secret hash header
  • Verify: GET /v3/transactions/{id}/verify
  • Callback: /checkout/flutterwave/callback
Cash on Delivery

Order created with payment_status=UNPAID, status=PENDING. Admin reviews in the panel and manually sets CONFIRMED. Confirmation email sent at that point. No payment gateway involved.

Admin Manual Push — /admin/notifications

  • Compose title (max 100 chars) + message body (max 300 chars)
  • Optional link URL (opens when user taps notification)
  • Choose audience: All Subscribers / Opted-In Users / All Devices
  • Live preview panel updates as you type
  • Full history log — all sent notifications, sender name, timestamp, success/fail status
  • Visible only to SUPER_ADMIN in sidebar under Settings

Section 8

AI Features

Public AI Chat Widget

Floating chat button on all public pages. Backend routes through AiAssistantService using GROQ LLaMA 3.3-70B (primary) with Gemini 2.0 Flash automatic fallback. Handles product questions, pricing, farm info, ordering, and delivery. Returns product suggestion cards inline in responses.

Admin AI Assistant — /admin/ai

Product Content

Input: product type + category. Output: name, short/full description, tags, price suggestion, unit. One-click insert into product form.

Business Plan

Generates investor-ready business plan — executive summary, market analysis, financial projections, operational strategy.

Sales Insights

Reads real sales data, returns: top performers, underperformers, seasonal patterns, pricing recommendations, action steps.

Blog Post Generator

Input: topic + category → 600+ word SEO blog post. Fetches Pexels image. Can auto-publish directly.

Auto-Publish Command

php artisan blog:auto-publish --topic="Poultry Farming" --category="Farming Tips"
php artisan blog:auto-publish   # uses 10 built-in farming topics
